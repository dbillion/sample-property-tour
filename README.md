# Aurel Residences — Interactive Property Tour

A sample real-estate showcase built with React, Three.js and Vite. Includes an orbitable 3D apartment concept, clickable SVG floor plan, room details, responsive layout and a demo enquiry flow.

## Important
This is a concept demo. The apartment layout, measurements, amenities and imagery are illustrative and are not a measured survey or a real listing. The enquiry form is frontend-only and does not transmit or store data.

## Run locally
`bun install`
`bun run dev`

## Build
`bun run build`
